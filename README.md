## 🚀 How to Install & Use in Antigravity

To use any of these skills in your local Antigravity environment:

### Install All Skills
```bash
# Clone the repository
git clone https://github.com/codedgamer25/antigravity-skills.git

# Copy skills to your Antigravity configuration directory
# On Windows (PowerShell):
Copy-Item -Path "antigravity-skills\*" -Destination "$env:USERPROFILE\.gemini\config\skills" -Recurse -Force

# On macOS / Linux:
mkdir -p ~/.gemini/config/skills
cp -R antigravity-skills/* ~/.gemini/config/skills/
```

### Install a Specific Skill
Pick any skill directory and copy it directly to your configuration folder:
```bash
# Example: Installing apple-design
cp -R antigravity-skills/apple-design ~/.gemini/config/skills/
```
